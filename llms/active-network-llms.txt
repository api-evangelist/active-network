# ACTIVE Network

> ACTIVE Network provides intelligent activity and event management software for
> communities and organizations, and publishes a set of read-only public data
> APIs on its AMP platform (api.amp.active.com). APIs are authenticated with an
> api_key query parameter and rate limited. Generated by the API Evangelist
> enrichment pipeline from ACTIVE Network's public developer documentation.

## APIs

- [Activity Search API v2](https://developer.active.com/docs/read/v2_Activity_API_Search): Search public activities and events from ACTIVE.com and ACTIVEkids.com. GET http://api.amp.active.com/v2/search. JSON. 2 calls/sec, 500,000/day.
- [Campground Search API](https://developer.active.com/docs/read/Campground_Search_API): Search campgrounds and campsites (ReserveAmerica data). GET http://api.amp.active.com/camping/campgrounds. XML. 2 calls/sec, 5,000/day.

## Authentication

- API key via the `api_key` query parameter. No OAuth or SSL required. Register: https://developer.active.com/member/register
